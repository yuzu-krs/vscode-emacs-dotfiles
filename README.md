# VSCode Emacs Dotfiles

VSCode を Emacs キーバインド中心で使うための設定。

## 方針

- エディタ操作: Emacs keybindings
- VSCode固有操作: Ctrl+; leader keybindings
- ターミナル操作: Git Bash / readline
- Git操作: lazygit
- テーマ: Dracula
- Neovim: 使わない

## 管理対象

- vscode/settings.json
- vscode/keybindings.json
- vscode/extensions.txt

## 必要な拡張機能

- Awesome Emacs Keymap
- Dracula Official
- Material Icon Theme
- Prettier
- GitHub Copilot
- GitLens

## 注意

APIキー、トークン、会社固有情報、自動承認設定、個人ホスト名はコミットしない。
